Frequently asked questions

Still deciding? Here's what people usually ask.

Is my data private?

Yes. Life Hub is built for one person's data at a time — everything you log is scoped to your account only, and stored passwords are encrypted rather than kept as plain text.

Is it really free? What's the catch?

It's free to sign up and use — no credit card required. There's no hidden tier or trial clock; this is a tool built for personal daily use, not a funnel.

Do I have to use all seven tools?

No. Habits, health, budget, nutrition, notes, to-dos, and vault are all independent — use one, use all of them, or ignore the rest.

Can I use it on my phone?

Yes — Life Hub is a responsive web app, so it works in any mobile browser without installing anything.

Can I get my data out, or delete my account?

Yes to both — Settings has a one-click JSON backup download, and Profile has a Delete Account option if you ever want to leave.
